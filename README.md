Just starting on my ricing journey with SwayWM!

- *Sway*: Compositor for Wayland
- *Waybar*: Status bar for Wayland
- *fuzzel*: Application launcher
- *foot*: Terminal emulator
- *swaync*: Sway notification center
- *grim* + slurp: Screenshot tools
- *wl-clipboard*: Clipboard utilities for Wayland
- *Thunar*: File manager
- *Firefox-esr*: Web browser

**Atajos clave para recordar**

- `Super + Enter` - Terminal
- `Super + D` - Launcher de apps
- `Super + B` - Navegador
- `Super + Shift + Q` - Cerrar ventana
- `Super + 1/2/3...` - Cambiar workspace
- `Super + H/J/K/L` - Navegar ventanas (vim style)
- `Super + R` - Modo redimensionar
- `Print` - Screenshot completo
- `Super + Print` - Screenshot selección
